# KlassenBattle – Mathe & Deutsch
- Lehrer/Schüler
- Mathe kariertes Blatt, Deutsch liniertes Blatt
- Schreiben mit Finger, Stift oder Maus
- KI bewertet das Blatt als Bild
- Bei Fehlern: Tipp statt Lösung
- Multiplayer via Socket.IO

Render: Build `npm install`, Start `npm start`.
Environment: `OPENAI_API_KEY` mit deinem API-Key setzen.
